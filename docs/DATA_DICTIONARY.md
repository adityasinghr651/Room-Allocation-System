# Data Dictionary — RoomAlloc AI

## Database Schema Reference (`data/roomalloc.db`)

### 1. `users`
Stores user authentication credentials and role assignments.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Unique user identifier |
| `username` | TEXT | UNIQUE, NOT NULL | Account login username |
| `password_hash` | TEXT | NOT NULL | Salted PBKDF2-HMAC-SHA256 password hash |
| `role` | TEXT | NOT NULL | User authorization role (`admin` or `student`) |
| `student_id` | TEXT | UNIQUE, NULLABLE | Foreign key mapping to `students.student_id` |
| `created_at` | TEXT | NOT NULL | ISO-8601 creation timestamp |

### 2. `students`
Stores candidate profiles and seating requirements.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Internal student record ID |
| `student_id` | TEXT | UNIQUE, NOT NULL | Student institutional identification code (e.g. `S001`) |
| `name` | TEXT | NOT NULL | Full candidate name |
| `group_id` | TEXT | NOT NULL | Student cohort/group code (e.g. `A`, `B`, `C`) |
| `requires_accessible_seat` | INTEGER | NOT NULL DEFAULT 0 | Flag indicating wheelchair/accessible desk requirement |
| `created_at` | TEXT | NOT NULL | ISO-8601 creation timestamp |

### 3. `rooms`
Configures examination venues and geometric seating bounds.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Unique venue identifier |
| `name` | TEXT | UNIQUE, NOT NULL | Room name (e.g. `Room A`) |
| `rows` | INTEGER | NOT NULL | Number of desk rows in the hall grid |
| `cols` | INTEGER | NOT NULL | Number of desk columns in the hall grid |
| `accessible_seats` | INTEGER | NOT NULL DEFAULT 0 | Count of designated accessible desks in front rows |
| `created_at` | TEXT | NOT NULL | ISO-8601 creation timestamp |

### 4. `allocation_runs`
Records CSP solver execution telemetry and conflict states.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Solver run execution ID |
| `status` | TEXT | NOT NULL | Outcome state (`success` or `failed`) |
| `assigned_count` | INTEGER | NOT NULL | Number of students successfully placed |
| `nodes_visited` | INTEGER | NOT NULL | Number of search states explored |
| `conflicts_json` | TEXT | NOT NULL | JSON serialized conflict diagnostics |
| `created_at` | TEXT | NOT NULL | ISO-8601 execution timestamp |
| `actor_id` | INTEGER | FOREIGN KEY (`users.id`) | Admin user who triggered the run |
| `execution_time_ms`| REAL | DEFAULT 0.0 | Search runtime in milliseconds |
| `backtracks_count` | INTEGER | DEFAULT 0 | Count of backtracking steps triggered |
| `diagonal_constraint`| INTEGER | DEFAULT 0 | Flag indicating if diagonal spacing was enforced |
| `use_lcv` | INTEGER | DEFAULT 1 | Flag indicating if LCV value ordering was used |
| `total_students` | INTEGER | DEFAULT 0 | Total students in problem instance |
| `total_seats` | INTEGER | DEFAULT 0 | Total seating capacity in problem instance |

### 5. `allocations`
Stores exact desk placements generated by a solver run.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Individual placement identifier |
| `run_id` | INTEGER | NOT NULL, FK (`allocation_runs`) | Associated solver run |
| `student_id` | TEXT | NOT NULL | Student placed at the desk |
| `name` | TEXT | NOT NULL | Student name snapshot |
| `group_id` | TEXT | NOT NULL | Student cohort snapshot |
| `room_id` | INTEGER | NOT NULL | Room containing the desk |
| `room_name` | TEXT | NOT NULL | Room name snapshot |
| `seat_id` | INTEGER | NOT NULL | Unique synthetic seat ID |
| `seat_label` | TEXT | NOT NULL | Human-readable seat code (e.g. `RoomA-R01-C02`) |
| `row_no` | INTEGER | NOT NULL | Row coordinate |
| `col_no` | INTEGER | NOT NULL | Column coordinate |
| `is_accessible` | INTEGER | NOT NULL | Whether the desk is an accessible desk |

### 6. `student_restrictions`
Stores explicit proximity separation rules between specific candidate pairs.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Restriction identifier |
| `student_id_1` | TEXT | NOT NULL | First candidate ID |
| `student_id_2` | TEXT | NOT NULL | Second candidate ID |
| `notes` | TEXT | NULLABLE | Reason or administrative justification |
| `created_at` | TEXT | NOT NULL | ISO-8601 creation timestamp |

### 7. `audit_log`
Tracks system events for auditability.
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY | Event log ID |
| `actor_id` | INTEGER | NULLABLE | User ID of the operator |
| `action` | TEXT | NOT NULL | Operation type (e.g. `student.create`, `allocation.run`) |
| `details` | TEXT | NOT NULL | Summary of modifications |
| `created_at` | TEXT | NOT NULL | ISO-8601 timestamp |
